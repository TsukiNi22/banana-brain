## v1.0.0 - 2026-10-30
### In Progress
- `-ffast-math` (`Optimized` mode) lets the compiler remove the finite checks (`std::isfinite`): a NaN coefficient, range or limit is not refused in this mode (its clang warning `-Wnan-infinity-disabled` is disabled, 3 unit tests fail there); `-fno-finite-math-only` would keep them

### Changed
- **[MAJOR]** One entry for every training: `NeuralNetwork::train(inputs, expected_outputs, options = {})` returns a `brain::TrainResult` and replaces `train<mean>(round | loss, ...)`. `brain::TrainOptions` (all optional, the defaults are one epoch and one update per sample): `epochs`, `batchSize` (mini-batch: 1 = per sample, n, 0 = the whole set), `shuffle` / `seed`, `mean`, `targetLoss`, `patience`, `validationIn` / `validationOut`, `stop` (`brain::StopCondition`: `Epochs`, `TargetLoss`, `Patience`) and `onEpoch` (a `brain::StopFn`, true = go on, wins over `stop`)
- The sums of the links of a brain network use four partial sums (the link j goes to the sum j % 4, then (0 + 1) + (2 + 3), the bias added last) and its sigmoid is `fastSigmoid`: the execution is about 1.5 times faster, the values differ from the ones of before by about 1e-7 (a training of a recurrent network that is sensitive can then go another way: the checksums of the tests were compared with a tolerance); the exact steps stop and the loops over the neurons are vectorized (the sums, then the activations of the whole array)
- The time steps of a brain network stop when no state moved by more than `threshold()` between two steps (to the bit when it is 0, the default): the next steps are copies; a network without loop settles after its depth
- On a gpu a brain network of at most `BRAIN_GPU_SINGLE_KERNEL_NEURONS` (256) neurons with a cap under 32 computes all its time steps in one launch of one block with a barrier between the steps, 20 to 30 % faster (a kernel for all the blocks with a barrier of the grid and one launch with a warp per neuron were slower than the launches and were not kept)
- **[MAJOR]** The default time steps of a raw brain network are `log2(n)` (before `4 log2(n)`: 3 steps at 10 neurons, 9 at 1000) and never under `BRAIN_STEPS_PATH_MARGIN` (1.1) times the farthest path in links from an input to an output, computed at the init whatever the cap says (the signal has to arrive); the execution and the training are 3 to 8 times faster with the default, the networks that need more steps (loops, memory) raise `stepsCap()`
- The execution and the training of a brain network on the host, with the same results to the bit (checked on the training of six networks: sigmoid, ReLU, linear, threshold, Adam with mini-batch, external function): the activation function is chosen once per execution instead of for every neuron (the functions of `brain/tools/activation.hpp` are inline), the buffers of `apply()` are reused, the output stored by the forward pass is used by the backward one instead of a new activation, and when every state of a step is the same to the bit as at the step before the next steps are copies (a network without loop, `LEFT_TO_RIGHT`, settles after its depth: the execution is 2.4 to 3.5 times faster and the training up to 1.6 times)
- Defaults of a raw brain network: `randomLinks()` is on (each neuron gets a random number of links at the init, between `minLinks()` and the cap, instead of as many as the cap allows) and `minLinks()` is 1 (a neuron keeps its last link: `allowOrphans()` needs `minLinks(0)`); the scenarios of the lab keep the full links and no minimum they were measured with
- Optimization pass with the same results (CPU and GPU): a layered network learns in place (no copy of the weights per sample), the execution copy of a brain network stops at its first free slot, the clone of every link is known (kept up to date by the link changes, used by the update, `weightInit` and the gpu), the update calls no `std::function`, the memory of the execution copy is kept when its size does not change, the gpu keeps its scratch buffers per thread (no allocation per call) and reads the slots of a large cap with one warp per neuron (`step_warp`, `back_step_warp`); measured in `audit/2026-10-25-benchmark.pdf` (ex: layered {1024,1024,10} 115 -> 21 ms per round, brain on the gpu with 13 hidden neurons 29 -> 2.8 ms)
- Speed of a raw brain network on the host, with the same results: the nearest neurons of each neuron are sorted once and kept to `2 cap + 8` (the rest only when they are all used), the inward links are packed once per change, the sums of `apply()` are kept for the backpropagation, a neuron without a link at a limit is skipped by the link changes (measured: 500 hidden neurons 166 -> 16 ms per round with Adam, CIRCLE 1.4 -> 1.0 ms)
- `train` sends the signed error of each output times the learning rate: `output - expected` for a layered network (descent), `expected - output` for a brain network (a score); the loss function only measures and stops `train(loss)` (with `mean`: one coefficient, the mean of the signed errors)
- Default caps of a raw brain network: the links are `min(100 % n, 3 sqrt(n))` (`BRAIN_LINKS_CAP_PERCENTAGE` 1.0, `BRAIN_LINKS_CAP_COMPUTING` 3 sqrt(n): 12 links at 16 neurons, 94 at 1000) and the time steps `min(100 % n, 4 log2(n))` (`BRAIN_STEPS_CAP_PERCENTAGE` 1.0)
- A brain network file (`.bn`, `.rbn`) where an input receives a link or an output sends one is refused (`InvalidNetworkFile`), and `size()` of a reduced network refuses sizes that would break the roles of its links (the init and the links created by the training already kept them)
- **[MAJOR]** The brain network is split in `brain::BrainNetwork` (reduced, execution only: the training calls throw `ReadOnlyNetwork`) and `brain::RawBrainNetwork` (execution and training, derives from it and gives a reduced copy with `reduce()`); `init<Brain>` creates the raw one
- **[MAJOR]** The neurons and the links are trivially copyable structs stored in `utils::system::HybridMemory` (GPU when available, else the RAM): `LayerNeuron` (`incoming`, `count`, `bias`) with the weights in their own memory, `BrainNeuron` / `BrainLink` (reduced), `RawBrainNeuron` / `RawBrainLink` (raw, a link is found twice with the same weight: the receiver for the execution, the clone on the sender for the backpropagation); no cache line alignment any more
- **[MAJOR]** The input / output sizes, the random range / function and the activation function belong to the network (`INetwork` / `ANetwork`) and `NeuralNetwork` applies its setters to it: they throw `NoNetwork` before `init<...>`
- **[MAJOR]** `train` is `train<mean>(round | loss, inputs, expected_outputs)` without hook: the loss of the outputs (times the learning rate) is the coefficient of the backpropagation, one per output (`mean = false`) or the mean (`mean = true`)
- `exec` executes without storing anything in the network (`apply(inputs) const`, thread-safe); `inputs()` / `apply()` are the non const forward of the training
- `init<Layered>` also takes the number of neurons of each layer (`brain::Layers`), the networks check their parameters and the current network is kept when they are invalid
- `loss` has the versions `loss<true>` (mean), `loss<false>` (each output) and the pair of both, with an optional coefficient
- `text_to_input` / `input_to_text` have the modes `Normal` (one value per character, byte / 255) and `Compact` (the bytes copied in the values)
- `brain::tools::sort(index, neurons, cap)` returns the ids of the `cap` nearest neurons, closest first, instead of filling a list in the neurons
- The networks share one GPU handler per mode for the whole program (finding a GPU takes a few hundred ms)
- **[MAJOR]** The inputs of a brain network are its first neurons and the outputs its last ones (`size(input, output)`); the raw network places them on the left and right edges of its space and the input neurons receive no link while the output ones send none
- The file of a brain network (`.bn`, `.rbn`) holds the number of time steps and the signal threshold, a `.rbn` also the percentages of its links and steps limits; a file with a layer that does not match its neurons or weights is refused
- `size()`, `input()` and `output()` restore the previous sizes when the network refuses the new ones

### Fixed
- `pathInit()` read past the end of its tables on some seeds in the `Optimized` mode (a crash of the init, ex: 35 inputs and 10 outputs on 85 neurons): it marked "no path" with the infinity, and `-ffast-math` folds the comparisons with it away; the mark is the largest finite value
- The include guards of `brain/NetworkType.hpp` and `brain/NetworkDefine.hpp` were the ones of `utils/network/NetworkType.hpp` and `utils/network/NetworkDefine.hpp`: a program using the network of libutils could not include banana-brain (renamed `BRAIN_NETWORKTYPE_H`, `BRAIN_NETWORKDEFINE_H`)
- A program that used a GPU crashed at its exit (each test run alone by `ctest`): the shared GPU handlers and the CUDA libraries are released at the exit, before the statics of libutils they use
- `loss.cpp` and `activation.cpp` were only in the sources of the executable: they are in the library
- `BRAIN_LINKS_CAP_COMPUTING` overflowed on a big network (`pow`): written as `2 log2(n) ln(n) / ln(1.1)`
- `brain::tools::get<bool>` read an undefined `bool` from a byte other than 0 or 1

### Added
- The lab (a local page and a C++ server engine on this library, with logic, curve, 2D and 3D tasks, scenarios with their settings, a 3D viewer and a log chart) is a development tool: it is not in the repository
- Mini-batch on every network: `batch(bool)`, `batch()` and `applyBatch()` are on `INetwork`; a layered network accumulates the gradients of the samples and applies their mean once (a reduced brain network refuses it)
- `applyAll(Dataset)` on every network and `NeuralNetwork::execAll(Dataset)`: the outputs of several samples, a brain network computes them together on the host (the states of the samples side by side: the links are read once per step for all of them, 1.4 to 2.8 times faster per sample, the same outputs as `apply()` to 1e-6); a layered network and a gpu one run `apply()` for each sample
- `threads(count)` on a brain network (0 = automatic by default, 1 = one thread): the time steps of a big network are shared between threads with a barrier at each step, one thread for each `BRAIN_THREADS_MIN_WORK` (131072) slots of links of a step (a small network stays on one thread), by chunks of `BRAIN_THREADS_CHUNK` (64) neurons so that the states are the same to the bit whatever the number of threads; a function of the user and a sequence stay on one thread
- `brain/tools/sum.hpp` (`rowSum`, `listSum`, `settled`, `stepThreads`) and `brain::tools::fastExp` / `fastSigmoid` (no call to the math library, about 1 ulp)
- The on / off rules of a raw brain network as flags like the ones of the cli of libutils: `brain::Rule`, `brain::rules::DEFAULT` / `NONE` / `ALL` / `LAB` (the rules of the lab), `addRules()`, `subRules()`, `setRules()`, `resetRules()`, `clearRules()` and `getRules()`; the single setters are the same bits and the `.rbn` holds the two new rules
- `INPUT_PATHS` rule (off by default): every input keeps a path to at least one output (built at the init with the paths of `pathInit()`, a removal that would cut the last one is put back), and `MOVE_LAST_LINK` rule (off by default): the last link of a neuron that would be removed under `weightMin` is moved to the nearest free neuron, with the weight of a new link, instead of being kept; the lab has both as options of the Server engine
- `rateDecay()`, `invertedLinks()`, `randomLinks()` and `minLinks()` on a raw brain network (the last settings of the lab that the class did not have), saved in the `.rbn` (a file with an invalid value is refused): the steps of the weights divided by `1 + decay * updates`, the limits of the links swapped (cut at `weightMax`, grown at `weightMin`), a random number of links per neuron at the init, a minimum of links a neuron keeps
- The score of the training of every network, as the activation function: `internalScoreFunction()` (`ScoreFunction::Difference`, `Sign`, `Loss`) or `scoreFunction(ScoreFn)` (wins), `scoreRate()` and `scores(outputs, expected)` on `INetwork` / `NeuralNetwork` (`train` sends `score * scoreRate * learningRate`; not saved in the files); the lab server uses them and no longer ignores any setting
- `sequence(steps)` / `applySequence(steps)` on a raw brain network: the inputs of each time step (step t reads `steps[t]`, the inputs are 0 after the last one), so the network has to remember what it saw; `inputs()` cancels a sequence, the backpropagation goes back through its steps, a sequence runs on the host
- Getters of a raw brain network: `rawNeurons()`, `rawLinks()` (copies of the raw memories) and `states()` (the states of every step of the last `apply()`)
- Training options of a raw brain network, all off by default and saved in the `.rbn` (a file with an invalid value is refused): `momentum()`, `adam()` (each weight moves by about the rate, the direction from the mean of its gradients), `stepLimit()`, `clampWeights()`, `directOutput()` (the score on the sum of an output without the slope of its activation), `batch()` / `applyBatch()` / `pending()` (mini-batch: the mean of the gradients applied at once), `lowNewLinks()` (a link added at `weightMax` starts at 5 % of the limits), `keepPaths()` (the last path of an input to an output is never cut); they run on the host when the network is on the gpu
- `revive()` on a raw brain network: a neuron stuck at 0 or 1 on every execution since the last call gets a bias of 0 and its inward weights halved (it had no gradient), the number revived is returned
- Init options of a raw brain network: `farLinks()` (slots of the cap given to random far neurons) and `pathInit()` (every input gets a path of at most the given number of links to every output, the paths already built are never given up)
- `leftToRight(bool)` / `leftToRight()` on a raw brain network: the links only go from a neuron to a neuron on its right (no loop), the list of the neurons on the left of each one is computed once (init or load) and used by the init and by the new links; the mode is saved in the `.rbn` and a file where a neuron receives from its right is refused in this mode
- The simulations of the explanation pages learn the same tasks with the same default (AND, OR, COPY, XOR, MAJ3) on both pages, so the two networks can be compared
- Live 2D simulations in the explanation pages (section "Watch it learn"): a layered network learning XOR and a raw brain network, forward passes then backpropagations over and over, with the values, weights, biases and the links created / removed (same rules as the C++ code, gradient checked against finite differences), a new random network (the brain one always with an output at most 3 hops from an input) or back to the example
- Explanation pages of the documentation (EN / FR, Simple and Technical levels, animations and live examples): `docs/layer-network.html` (execution layer after layer, backpropagation) and `docs/brain-network.html` (time steps, threshold, links and steps limits, score training, links changing at the weight limits)
- Arch Linux packages (`.pkg.tar.zst`, same names, channels and dependencies as the RPM / DEB, libutils >= 4.2.0) built by `package_release` (CPack `External` generator, `cmake/package/CPackArch.cmake`, needs `bsdtar`), checked, signed and published by `Build - Packages (CI/CD)` in the pacman repository `arch/x86_64` of `gh-pages` (indexed by `Sync Packages (CD)`), and `setup.sh` registers it on Arch-based distributions
- Every function checks the frozen state, the network, the sizes, the datasets and its parameters (`NoNetwork`, `InvalidInputSize`, `InvalidOutputSize`, `InvalidCoefficient`, `InvalidLearningRate`, `InvalidArgument`...)
- Default setup of the networks (`init_`): the layers and the weights, the reduced neurons and slots, the neurons of the raw network placed randomly and linked to as many of their nearest ones as `cap` allows, closest first, in a random direction, with weights at 1.0 and biases at 0.0 until `weightInit()` / `biasInit()` (the inputs only send, the outputs only receive) (limit `linksCap`: the smallest of a percentage of the neurons and a function of their number), and the random `weightInit` / `biasInit` (range or function, `fallback` on 0)
- Serialization and files: `serialize()` / `deserialize()` of every network, `NeuralNetwork::save(path)` / `load(path)` (`.ln`, `.bn`, `.rbn`, `.net`, magic bytes `0x22` + `'l'` / `'b'` / `'r'`, activation byte), the refusal of a bad, truncated or inconsistent file, and the warning for the functions that can't be saved
- Exception codes `ReadOnlyNetwork`, `CustomActivationRequired`, `CustomRandomRequired`, `CustomLinksCapRequired`
- Tools: the losses (`mse`, `cross_entropy`), the activations (`sigmoid`, `linear`, `relu`), the little endian bytes (`put`, `get`, `fits`), `shuffle`, `rand_sets`, the generator used by the positions and the random weights
- Unit tests of the types, the checks, the three networks, the files, `NeuralNetwork` and the tools
- Backpropagation: `LayerNetwork` goes down the gradient of the error of each output (activation derivatives, estimated for an external function); `RawBrainNetwork` goes back through the time steps and reinforces (positive score) or weakens (negative) the links that made the outputs, a link and its clone keeping the same weight
- Links of a raw brain network that change with the weights: any link of a neuron is removed when the absolute value of its weight falls to `weightMin()` (never its last link, nor the last inward link of an output or hidden neuron, nor the last outward link of an input) and, when it rises to `weightMax()`, the nearest neuron that is still free is linked with a random weight, between half and all of the mean of the two nearest links of the list that did not cause it (fewer, or the middle of the limits, without them) and inside the limits (`BRAIN_WEIGHT_MIN` 0.01, `BRAIN_WEIGHT_MAX` 2.0), `allowOrphans()` / `disallowOrphans()` (default) lets the last links be removed
- Forward pass of the networks: `LayerNetwork` layer after layer, `BrainNetwork` / `RawBrainNetwork` by time steps (`compute_` without state for `exec`, `apply()` that keeps the sums, the outputs and the states for the training)
- Computing on the gpu that stores the memories (`brain::tools::gpu`, `include/brain/tools/compute.hpp`): the layers, the time steps of the brain networks and the training forward run as kernels on the device buffers of the `HybridMemory` (CUDA driver and NVRTC loaded at runtime, compiled once per context), the backpropagation too (`layersBack`, `stepsBack`: the gradient and the update of the weights, the clones and the biases are made on the device, only the links changing (`relink_`) is done on the host), the host computes instead without the CUDA headers (optional, found by the cmake; the driver and NVRTC stay loaded at runtime), with an external activation function or on a failure
- Memory information of a network: `onGpu()`, `memoryMode()`, `requestedMode()`, `gpu()`, `gpuName()`, `gpuMemory()` (what `HybridMemory` / the shared gpu handler provide) and `memory()` (bytes of the memories of the network)
- Time steps of a brain network: `stepsCap(percentage | fn)`, `resetStepsCap()` and the getters `stepsCap()` / `linksCap()` (`BRAIN_STEPS_CAP_*`: 25 % of the neurons, `4 log2(n)`), the signal `threshold()` (`BRAIN_SIGNAL_THRESHOLD`, a placeholder at 0) and the exception code `CustomStepsCapRequired`

### Removed
- The workflow `Merge - libutils (CD)` (it did nothing) and the downstream notification of `docker-image` (the `notify-downstream` job, the `[release]` keyword of a commit and the secret `DOWNSTREAM_REPO_TOKEN`)
- `NetworkType::Banana`, the hooks `BackpropagationFn` / `BackpropagationsFn`, `NeuralNetwork::seed` and the memory `load()` / `unload()` of the networks (the codes `NetworkNotLoaded`, `NetworkAlreadyLoaded`, `FrozenNetwork`, `DeadNetwork` and `InvalidPercentage` stay reserved, not thrown yet)

## v0.0.0 - 2026-10-17
### Added
- Nothing executes yet: the project, its packages and its documentation exist, every class and function has its final signature with an empty body (the logic comes with the next versions)
- Architecture of the library (every signature, no logic yet): `brain::NeuralNetwork` (`utils::type::Freezable`, `init<NetworkType>`, configuration setters / getters, `train`, manual training, `exec`, `load` / `save`), the network family `brain::INetwork` -> `brain::ANetwork` -> `brain::LayerNetwork` / `brain::BrainNetwork`, the enums `NetworkType` / `ActivationFunction` / `LossFunction`, the value types `IType` / `UIType` / `FType`, the neuron structs `LayerNeuron` / `BrainNeuron` (cache line aligned) and the tools `brain::tools::` (`generator`, `rand`, `rand_unsigned_integer`, `rand_floating`, `shuffle`, `rand_sets`, `text_to_input`, `input_to_text`)
- Exception codes of the library (`utils::exception::ExternalCode::NoNetwork`, `NetworkNotLoaded`, `FrozenNetwork`, `InvalidInputSize`...) generated from `cmake/config/exceptions/brain.json` and installed with the headers
- Static library `libbrain.a` (`_debug`, `_asan`) with `find_package(brain)` / `brain::brain`, RPM/DEB packages like libutils (`libbrain`, `-dev`, `-dev-op` / `-dev-db` / `-dev-as`, `-op` / `-db` / `-as`, `-pre` channel) and the Windows ones (`mingw64-libbrain*`, MinGW-w64 cross compilation)
- Unit tests (GoogleTest, `tests/`) of the default states, the types and the compile time checks of `train`
- Workflows of [cpp_project_template](https://github.com/TsukiNi22/cpp_project_template): `Dispatch (CI/CD)`, `Unit Tests (CI)`, `Build (CI)`, `Build - Packages (CI/CD)`, `Release - GitHub (CD)`, `Docs - Pages (CD)`, plus `Style - xstyle (CI)` and `Merge - libutils (CD)` (reserved, does nothing yet)
- HTML documentation (`docs/`: technical page + interactive project graph, EN / FR, published on GitHub Pages)
- `setup.sh` (package repository + GPG key + installation), README, CHANGELOG, license CC BY-NC-SA 4.0
