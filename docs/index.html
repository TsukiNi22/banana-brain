banana-brain technical documentationDocumentation technique de banana-brain

C++20 neural network library on top of libutils: one NeuralNetwork for several kinds of networks (layered, brain), their training and the dataset tools. The tag v0.0.0 is the architecture only; the repository goes on with the memories, the serialization and the tools, the forward pass and the backpropagation come next.Bibliothèque C++20 de réseaux de neurones basée sur libutils : un NeuralNetwork pour plusieurs types de réseaux (par couches, cerveau), leur entraînement et les outils de jeux de données. Le tag v0.0.0 est l'architecture seule ; le dépôt continue avec les mémoires, la sérialisation et les outils, le calcul avant et la rétropropagation viennent ensuite.

1. Overview1. Vue d'ensemble

banana-brain is a static C++20 library (libbrain.a) built on libutils. Everything is in the namespace brain:: (tools in brain::tools::). A brain::NeuralNetwork owns one network (brain::INetwork) created by init<NetworkType>(), configures it (seed, size, activation / loss functions, learning rate), trains it (automatic rounds or a manual loop) and runs it (exec).banana-brain est une bibliothèque statique C++20 (libbrain.a) basée sur libutils. Tout est dans le namespace brain:: (les outils dans brain::tools::). Un brain::NeuralNetwork possède un réseau (brain::INetwork) créé par init<NetworkType>(), le configure (graine, taille, fonctions d'activation / de perte, taux d'apprentissage), l'entraîne (tours automatiques ou boucle manuelle) et l'exécute (exec).

Status (after v0.0.0): in progress. Written: the checks and errors of every function, the memories of the neurons (utils::system::HybridMemory, GPU when available), the default setup of the three networks (init_, weightInit, biasInit), the serialization and save / load, the losses, the activations, the datasets, the text conversion and the neighbour search. The forward pass of the three networks (compute_, apply()) and the backpropagation of the networks (backpropagation) are written. Open: train sends the loss as the coefficient (always positive for the mean squared error), while a layered network needs the signed error and a brain network a score; call backpropagation by hand with them.État (après v0.0.0) : en cours. Écrit : les vérifications et erreurs de chaque fonction, les mémoires des neurones (utils::system::HybridMemory, GPU si disponible), la mise en place par défaut des trois réseaux (init_, weightInit, biasInit), la sérialisation et save / load, les pertes, les activations, les jeux de données, la conversion de texte et la recherche de voisins. Le calcul avant des trois réseaux (compute_, apply()) et la rétropropagation des réseaux (backpropagation) sont écrits. Ouvert : train envoie la perte comme coefficient (toujours positive pour l'erreur quadratique), alors qu'un réseau par couches veut l'erreur signée et un réseau cerveau un score ; appeler backpropagation à la main avec eux.

2.1 Packages2.1 Paquets

The packages follow the libutils layout: a global package pulling the headers and the optimized library, one library package per build mode (-op, -db, -as) and the matching CMake configuration (-dev-op, -dev-db, -dev-as). Each library package requires the libutils package of the same mode. The -pre suffix is the unstable channel. setup.sh registers the package repository (tsukini22.github.io/banana-brain) and installs the global package.Les paquets suivent l'organisation de libutils : un paquet global qui tire les en-têtes et la bibliothèque optimisée, un paquet de bibliothèque par mode de build (-op, -db, -as) et la configuration CMake correspondante (-dev-op, -dev-db, -dev-as). Chaque paquet de bibliothèque requiert le paquet libutils du même mode. Le suffixe -pre est le canal instable. setup.sh enregistre le dépôt de paquets (tsukini22.github.io/banana-brain) et installe le paquet global.

sudo dnf install libbrain                 # libbrain-dev + libbrain-op
sudo dnf install libbrain-db libbrain-as   # Debug / Asan modes (+ libutils-db / libutils-as)
sudo dnf install mingw64-libbrain         # Windows (MinGW sysroot)
sudo apt install libbrain
sudo apt install libbrain-db libbrain-as
sudo pacman -S libbrain                  # libbrain-dev + libbrain-op (repository [brain] added by setup.sh)

3.2 Neurons and links3.2 Neurones et liens

The neurons are stored in a utils::system::HybridMemory (GPU when available, else the RAM), which copies its elements as bytes: every struct is trivially copyable (checked by static_assert), so a neuron holds no std::vector. The variable parts (the weights, the links) are in other memories of the network and the neuron only gives where they start and how many there are, or they are found from its index. The structs are not aligned on a cache line: that would pad a 4 bytes neuron to 64 bytes in the memory of the GPU.Les neurones sont stockés dans une utils::system::HybridMemory (GPU si disponible, sinon la RAM), qui copie ses éléments comme des octets : chaque struct est trivialement copiable (vérifié par static_assert), donc un neurone ne contient aucun std::vector. Les parties variables (les poids, les liens) sont dans d'autres mémoires du réseau et le neurone donne seulement où elles commencent et combien il y en a, ou elles se retrouvent depuis son indice. Les structs ne sont pas alignées sur une ligne de cache : un neurone de 4 octets serait étendu à 64 octets dans la mémoire du GPU.

4.1 Execution: without state, and for the training4.1 Exécution : sans état, et pour l'entraînement

apply(inputs) const executes the network without storing anything: it checks the inputs (not empty, the size set by size()) in ANetwork then calls compute_(inputs), the calculation of each network. Several threads can execute the same network at once. For the training, inputs(values) then apply() (non const) keep what the backpropagation needs, then backpropagation(coef | coefs).apply(inputs) const exécute le réseau sans rien stocker : il vérifie les entrées (non vides, taille réglée par size()) dans ANetwork puis appelle compute_(inputs), le calcul de chaque réseau. Plusieurs threads peuvent exécuter le même réseau en même temps. Pour l'entraînement, inputs(valeurs) puis apply() (non const) gardent ce dont la rétropropagation a besoin, puis backpropagation(coef | coefs).

LayerNetwork: layer after layer, each neuron is activation(bias + Σ weight × output of the previous layer), the inputs feed the first layer and the outputs are the last one. BrainNetwork / RawBrainNetwork: time steps. The first input neurons (ids 0..input-1) hold the inputs, the last output neurons are the outputs (size(input, output) is needed and both have to fit in the neurons); at each step every other neuron computes activation(bias + Σ weight × output, at the previous step, of the neuron it is linked to) and the outputs are read after the last step. A signal whose absolute value is under the threshold() is cancelled (set to 0) at each step, to stop the signals too weak to matter. The memories are read on the host (a GPU memory is fetched once).LayerNetwork : couche après couche, chaque neurone vaut activation(biais + Σ poids × sortie de la couche précédente), les entrées alimentent la première couche et les sorties sont la dernière. BrainNetwork / RawBrainNetwork : pas de temps. Les input premiers neurones (ids 0..input-1) portent les entrées, les output derniers sont les sorties (size(input, output) est nécessaire et les deux doivent tenir dans les neurones) ; à chaque pas chaque autre neurone calcule activation(biais + Σ poids × sortie, au pas précédent, du neurone auquel il est lié) et les sorties sont lues après le dernier pas. Un signal dont la valeur absolue est sous le threshold() est annulé (mis à 0) à chaque pas, pour arrêter les signaux trop faibles pour compter. Les mémoires sont lues sur l'hôte (une mémoire GPU est récupérée une fois).

Sur un RawBrainNetwork un lien reçoit le même poids sur ses deux slots.

4.3 Links limit4.3 Limite de liens

The slots of links of a neuron (cap) are min(percentage * neurons, hook(neurons)), between 1 and neurons - 1 (0 with a single neuron). The default percentage is 10 % and the default hook log1.1(n^(2 log2 n)): for a small network the hook gives more than the other neurons, so the percentage is the limit; from about 33 000 neurons the hook is. linksCap(percentage) (0 < percentage <= 1), linksCap(fn) and resetLinksCap() change it and set the network up again; linksCap() returns the pair <percentage, hook>. The time steps of the execution work the same way (stepsCap(percentage | fn), resetStepsCap(), getter stepsCap(), at least 1 step, without setting the network up again): the defaults BRAIN_STEPS_CAP_* are 25 % of the neurons and 4 log2(n). threshold(value) / threshold() (>= 0) set and read the signal threshold of the execution.Les slots de liens d'un neurone (cap) valent min(pourcentage * neurones, hook(neurones)), entre 1 et neurones - 1 (0 avec un seul neurone). Le pourcentage par défaut est 10 % et le hook par défaut log1.1(n^(2 log2 n)) : pour un petit réseau le hook donne plus que les autres neurones, donc le pourcentage est la limite ; à partir d'environ 33 000 neurones, c'est le hook. linksCap(pourcentage) (0 < pourcentage <= 1), linksCap(fn) et resetLinksCap() le changent et remettent le réseau en place.

5. NeuralNetwork5. NeuralNetwork

5.1 Configuration5.1 Configuration

The network is created first by init<NetworkType>() (it replaces the existing one only if the parameters are valid). Its random range / function, activation and size belong to the network: NeuralNetwork applies the setters to it and reads the getters from it, so they throw NoNetwork before init, and a new network starts with its own defaults. The learning rate and the loss function stay in NeuralNetwork (training only). An external function resets the internal one and the other way round: the pair <enum, function> returned by activationFunction() / lossFunction() tells which one is active.Le réseau est d'abord créé par init<NetworkType>() (il ne remplace l'existant que si les paramètres sont valides). Sa plage / fonction aléatoire, son activation et sa size appartiennent au réseau : NeuralNetwork lui applique les setters et lit les getters depuis lui, donc ils lèvent NoNetwork avant init, et un nouveau réseau repart de ses propres défauts. Le taux d'apprentissage et la fonction de perte restent dans NeuralNetwork (entraînement seul). Une fonction externe remet l'interne à zéro et inversement : la paire <enum, fonction> renvoyée par activationFunction() / lossFunction() dit laquelle est active.

5.2 Training5.2 Entraînement

train<mean>(round, inputs, expected_outputs) runs n rounds over the dataset; train<mean>(loss, inputs, expected_outputs) runs until the loss (without the learning rate) is under the given trigger (abs, checked after each sample). For each sample: inputs(), apply(), the loss of the outputs against the expected ones times the decayed learning rate, backpropagation(), then the decay step. mean = false (default) gives one coefficient per output to the backpropagation, mean = true a single coefficient (the mean). Everything is checked before the first sample: the network and a loss function exist, the datasets have the same size, are not empty and match size(). The first argument must be exactly a brain::UIType (rounds) or a brain::FType (loss): train(10, ...) with an int is ambiguous, write brain::UIType{10} or 0.1f.train<mean>(round, inputs, expected_outputs) fait n tours sur le jeu de données ; train<mean>(loss, inputs, expected_outputs) tourne jusqu'à ce que la perte (sans le taux d'apprentissage) passe sous le déclencheur donné (abs, vérifié après chaque échantillon). Pour chaque échantillon : inputs(), apply(), la perte des sorties contre celles attendues fois le taux d'apprentissage décru, backpropagation(), puis le pas de décroissance. mean = false (défaut) donne un coefficient par sortie à la rétropropagation, mean = true un seul coefficient (la moyenne). Tout est vérifié avant le premier échantillon : le réseau et une fonction de perte existent, les jeux ont la même taille, ne sont pas vides et respectent size(). Le premier argument doit être exactement un brain::UIType (tours) ou un brain::FType (perte) : train(10, ...) avec un int est ambigu, écrire brain::UIType{10} ou 0.1f.

The manual loop exposes each step: inputs(values), apply(), then loss(output, expected) (one output), loss<true>(outputs, expected, coef = 1) (mean), loss<false>(outputs, expected, coef = 1) (each output times coef) or loss(outputs, expected, coef = 1) (the pair <each, mean> in one pass), and backpropagation(coef) / backpropagation(coefs) (finite coefficient, one per output).La boucle manuelle expose chaque étape : inputs(valeurs), apply(), puis loss(sortie, attendu) (une sortie), loss<true>(sorties, attendues, coef = 1) (moyenne), loss<false>(sorties, attendues, coef = 1) (chaque sortie fois coef) ou loss(sorties, attendues, coef = 1) (la paire <chaque, moyenne> en un passage), et backpropagation(coef) / backpropagation(coefs) (coefficient fini, un par sortie).

Backpropagation follows an apply() (its sums, outputs and states are kept) and the learning rate is already in the coefficients. LayerNetwork: the classic one, a coefficient is the error of an output (positive = too high), the weights and biases go down the gradient layer by layer (derivative of the activation, estimated around the sum for an external function). RawBrainNetwork: a coefficient is a score (positive = good); going back through the time steps, the links and biases that made the output are strengthened (weakened for a negative score), a link and its clone keeping the same weight. The mean squared error is an error and not a score: setting it for a brain network warns (ErrorLossOnBrain). When the memories are stored on a CUDA gpu (and the activation is not an external function) the gradients and the update of the weights, the clones and the biases run there (brain::tools::gpu::layersBack / stepsBack); only the change of the links is done on the host.La rétropropagation suit un apply() (ses sommes, sorties et états sont gardés) et le taux d'apprentissage est déjà dans les coefficients. LayerNetwork : la classique, un coefficient est l'erreur d'une sortie (positif = trop haute), les poids et biais descendent le gradient couche par couche (dérivée de l'activation, estimée autour de la somme pour une fonction externe). RawBrainNetwork : un coefficient est un score (positif = bon) ; en remontant les pas de temps, les liens et biais qui ont fait la sortie sont renforcés (affaiblis pour un score négatif), un lien et son clone gardant le même poids. L'erreur quadratique est une erreur et pas un score : la choisir pour un réseau cerveau avertit (ErrorLossOnBrain).

The links change with the weights: a link is removed (with its clone) when |weight| <= weightMin() and, when |weight| >= weightMax(), the nearest neuron that is still free is linked (within the links cap) with a random weight between half and all of the mean of the two nearest links of the list that did not cause it (fewer, or the middle of the limits, without them), always inside the limits (defaults BRAIN_WEIGHT_MIN 0.01 and BRAIN_WEIGHT_MAX 2.0; weightMin, weightMax, weightLimits). It never removes the last link of a neuron, nor the last inward link of an output or hidden neuron, nor the last outward link of an input, unless allowOrphans() (disallowOrphans() by default). The limits and the mode are saved in the .rbn. On a CUDA gpu a kernel checks whether a link is at a limit: if none is, nothing is read back and the execution copy is rebuilt on the device.Les liens changent avec les poids : un lien est supprimé (avec son clone) quand |poids| <= weightMin() et, quand |poids| >= weightMax(), le plus proche voisin encore libre est lié (dans le cap des liens) avec un poids aléatoire entre la moitié et la totalité de la moyenne des deux liens les plus proches de la liste qui ne l'ont pas provoqué (moins, ou le milieu des limites, sans eux), toujours dans les limites (défauts BRAIN_WEIGHT_MIN 0.01 et BRAIN_WEIGHT_MAX 2.0 ; weightMin, weightMax, weightLimits). Jamais le dernier lien d'un neurone, ni le dernier lien entrant d'une sortie ou d'un neurone caché, ni le dernier lien sortant d'une entrée, sauf avec allowOrphans() (disallowOrphans() par défaut). Les limites et le mode sont sauvegardés dans le .rbn. Sur un GPU CUDA, un kernel vérifie si un lien est à une limite : sinon, rien n'est relu et la copie d'exécution est reconstruite sur le périphérique.

5.3 Usage, freeze, files5.3 Usage, gel, fichiers

exec(inputs) runs the network without touching its content (apply(inputs) const of the network): it is the only call allowed once the network is frozen (freeze() of utils::type::Freezable). Every other call that edits the object (init, setters, learningRate, train, inputs, apply(), backpropagation, weightInit, biasInit, load, clear) throws the Frozen error of libutils. save(path) / load(path) write and read the file of the network (4.4): an unknown extension only warns, the kind of network comes from the magic bytes, and the current network is replaced only when the file is valid. clear() removes the network and resets the training state (and the settings that belong to the network).exec(inputs) exécute le réseau sans toucher à son contenu (apply(inputs) const du réseau) : c'est le seul appel permis une fois le réseau gelé (freeze() de utils::type::Freezable). Tout autre appel qui modifie l'objet (init, setters, learningRate, train, inputs, apply(), backpropagation, weightInit, biasInit, load, clear) lève l'erreur Frozen de libutils. save(path) / load(path) écrivent et lisent le fichier du réseau (4.4) : une extension inconnue avertit seulement, le type de réseau vient des magic bytes, et le réseau actuel n'est remplacé que si le fichier est valide. clear() supprime le réseau et remet l'état d'entraînement à zéro (et les réglages qui appartiennent au réseau).
