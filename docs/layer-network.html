How a layered network worksComment marche un réseau par couches

The LayerNetwork of banana-brain: the execution layer after layer, then the training that sends the error back.Le LayerNetwork de banana-brain : l'exécution couche après couche, puis l'entraînement qui renvoie l'erreur en arrière.

In one sentence: numbers go in on the left, each layer mixes them with its weights, the last layer gives the answer, and training nudges every weight a little so the answer gets closer to the right one.En une phrase : des nombres entrent à gauche, chaque couche les mélange avec ses poids, la dernière couche donne la réponse, et l'entraînement pousse un peu chaque poids pour que la réponse se rapproche de la bonne.

In one sentence: a feed-forward network, out = f(bias + Σ w·in) per neuron and layer by layer, trained by classic backpropagation (gradient descent on the error of each output, the learning rate already in it), on the CPU or the CUDA gpu that stores the memories.En une phrase : un réseau à propagation avant, out = f(biais + Σ w·in) par neurone et couche par couche, entraîné par rétropropagation classique (descente de gradient sur l'erreur de chaque sortie, le taux d'apprentissage déjà dedans), sur le CPU ou sur le GPU CUDA qui stocke les mémoires.

1. The ideaL'idée

Picture a row of judges. The first row of judges looks at the raw facts (the inputs), each judge gives a score; the next row only looks at the scores of the row before, and so on. The last row gives the final verdict (the outputs).Imaginez des rangées de juges. La première rangée regarde les faits bruts (les entrées), chaque juge donne une note ; la rangée suivante ne regarde que les notes de la rangée d'avant, et ainsi de suite. La dernière rangée donne le verdict (les sorties).

Each judge trusts some judges of the row before more than others: that trust is a weight. Training is telling the judges how wrong the verdict was, so each one adjusts how much it trusts the others.Chaque juge fait plus confiance à certains juges de la rangée d'avant qu'à d'autres : cette confiance est un poids. Entraîner, c'est dire aux juges à quel point le verdict était faux, pour que chacun ajuste sa confiance dans les autres.

brain::LayerNetwork holds a list of layers (brain::Layers, the number of neurons of each one). Neuron k of layer l computes s = b + Σj wj·ol−1,j and outputs o = f(s); layer 0 reads the inputs (size(input, output) sets their number), the last layer is the output. The neurons (LayerNeuron {incoming, count, bias}) and the weights are two HybridMemory: on the gpu when there is one.brain::LayerNetwork garde une liste de couches (brain::Layers, le nombre de neurones de chacune). Le neurone k de la couche l calcule s = b + Σj wj·ol−1,j et sort o = f(s) ; la couche 0 lit les entrées (size(input, output) fixe leur nombre), la dernière couche est la sortie. Les neurones (LayerNeuron {incoming, count, bias}) et les poids sont deux HybridMemory : sur le GPU quand il y en a un.

apply(inputs) const: nothing kept, several threads at once.apply(inputs) const : rien n'est gardé, plusieurs threads à la fois.

3. How big, how fastQuelle taille, quelle vitesse3. Size and costTaille et coût

Every neuron has one weight per neuron of the layer before. A network with 2 inputs, 4 hidden neurons and 1 output has 2×4 + 4×1 = 12 weights and 5 biases. One training step goes over every weight twice (once forward, once back).Chaque neurone a un poids par neurone de la couche d'avant. Un réseau avec 2 entrées, 4 neurones cachés et 1 sortie a 2×4 + 4×1 = 12 poids et 5 biais. Un pas d'entraînement passe deux fois sur chaque poids (une fois en avant, une fois en arrière).

With layer sizes n0 (the inputs), n1, …, nL:Avec les tailles n0 (les entrées), n1, …, nL :

W=∑l=1Lnl−1·nl(1)

The forward pass and the backward pass are each O(W) multiply-adds; memory is W·sizeof(FType) for the weights plus 24 bytes per neuron. On the gpu (brain::tools::gpu::layers / layersBack) one kernel runs per layer (a thread per neuron), so the layers stay sequential but the neurons of a layer run together.Le calcul avant et le calcul arrière font chacun O(W) multiplications-additions ; la mémoire vaut W·sizeof(FType) pour les poids plus 24 octets par neurone. Sur le GPU (brain::tools::gpu::layers / layersBack), un kernel tourne par couche (un thread par neurone) : les couches restent l'une après l'autre, les neurones d'une couche tournent ensemble.

6. Worked exampleExemple détaillé

The figure of section 2 in code: build the network, run it, give the error, run it again.La figure de la section 2 en code : construire le réseau, l'exécuter, donner l'erreur, l'exécuter à nouveau.

brain::LayerNetwork network(brain::Layers{2, 1}); // 2 hidden neurons, 1 output
network.size(2, 1); // 2 inputs, 1 output
network.internalActivationFunction(brain::ActivationFunction::Sigmoid);
network.weightInit(); // random weights in the rand() range (the example uses fixed ones)

network.inputs({1.0, 0.5});
const brain::FType output = network.apply()[0]; // 0.582 with the weights of the figure
network.backpropagation(0.5 * (output - 1.0)); // -0.209: too low, the output goes up
network.inputs({1.0, 0.5});
(void)network.apply(); // 0.607

After 100 steps with the same rate the output reaches 0.922 (section 4 computes it live).Après 100 pas au même taux, la sortie atteint 0.922 (la section 4 le calcule en direct).

7. Common mistakesErreurs courantes7. PitfallsPièges

  • "Any number works as the error." The coefficient must say which way the answer is wrong: positive = too high, negative = too low. A squared error (always positive) would push every answer down.« N'importe quel nombre sert d'erreur. » Le coefficient doit dire dans quel sens la réponse est fausse : positif = trop haute, négatif = trop basse. Une erreur au carré (toujours positive) pousserait toutes les réponses vers le bas.
  • "Bigger steps learn faster." Up to a point: a too big rate jumps over the right answer and swings around it (try a rate of 3 in section 4).« De plus grands pas apprennent plus vite. » Jusqu'à un certain point : un taux trop grand saute par-dessus la bonne réponse et oscille autour (essayez un taux de 3 dans la section 4).
  • "I can train without running it first." Training needs the numbers of the last run: always apply() before backpropagation().« Je peux entraîner sans l'exécuter avant. » L'entraînement a besoin des nombres du dernier passage : toujours apply() avant backpropagation().
  • Sign of the coefficient: it is the error ∂L/∂y (already times the rate); train still sends the loss value, always positive for the MSE: compute rate·(y − t) and call backpropagation yourself for a real descent.Signe du coefficient : c'est l'erreur ∂L/∂y (déjà fois le taux) ; train envoie encore la valeur de la perte, toujours positive pour la MSE : calculez taux·(y − t) et appelez backpropagation vous-même pour une vraie descente.
  • Saturation: the sigmoid derivative o(1−o) is close to 0 near 0 and 1: the gradient vanishes in deep or saturated networks; ReLU keeps 1 for a positive sum (0 otherwise: a dead neuron never learns again).Saturation : la dérivée de la sigmoïde o(1−o) est proche de 0 près de 0 et de 1 : le gradient s'éteint dans les réseaux profonds ou saturés ; ReLU garde 1 pour une somme positive (0 sinon : un neurone mort n'apprend plus).
  • External activation: its derivative is estimated by a central difference (step 1e-3) and it runs on the host only: no gpu for that network.Activation externe : sa dérivée est estimée par une différence centrée (pas 1e-3) et elle ne tourne que sur l'hôte : pas de GPU pour ce réseau.
  • Optimized build: -ffast-math removes the std::isfinite checks, a NaN coefficient is not refused there.Build Optimized : -ffast-math retire les vérifications std::isfinite, un coefficient NaN n'y est pas refusé.
